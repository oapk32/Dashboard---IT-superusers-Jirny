Jak zapnout skutečný multiplayer na GitHub Pages
  1. Ve Firebase Console vytvoř projekt a webovou aplikaci.
  2. V Authentication → Sign-in method zapni Anonymous.
  3. V Realtime Database vytvoř databázi a zkopíruj její databaseURL.
  4. Do firebaseConfig na začátku skriptu dole vlož hodnoty z webové aplikace a URL databáze.
  5. V Realtime Database → Rules vlož pravidla níže a publikuj je. Pak HTML nahraj na GitHub Pages.

      
Bez Firebase běží jen lokální demo v jednom okně. Jména a statistiky jsou po zapnutí multiplayeru viditelné dalším hráčům.
